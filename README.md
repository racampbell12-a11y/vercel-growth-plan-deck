# Vercel Growth Plan Deck

Standalone submission copy of the Vercel 2026 growth plan deck.

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

## v0 workflow

1. Push this folder to a standalone GitHub repo.
2. Import that repo into v0 as existing code.
3. Verify the preview.
4. Publish the project and use the published URL for submission.
